# 01. Integrated Financial Planning Model

## Objective
Develop an integrated financial planning model for a fictional UK-based industrial automation and robotics company.

## Scope
- 5-year strategic financial plan
- Annual budget and rolling forecast
- Revenue and cost forecasting
- Headcount and payroll planning
- CAPEX and working capital
- Integrated Profit & Loss, Balance Sheet and Cash Flow
- Scenario and sensitivity analysis

## Tools
Microsoft Excel

In development
